# Sajib Hossen Tonmoy — Portfolio

A responsive single-page portfolio website ready for GitHub Pages.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your portfolio URL.

## Before publishing
Replace the placeholder email and GitHub/LinkedIn links in `index.html` with your real contact details.
